NeyroCraft — готовый сервер Minecraft (Paper 26.3, вход с 1.21.11 и новее)
=========================================================================

ЧТО ВНУТРИ
  minecraft-server\   — сам сервер: Paper, все плагины, миры, настройки
  source\             — исходный код своих плагинов, моделей, звуков и трейлера
  promo\              — трейлер, баннер, иконка, аватар и обложка для ВК, тексты рекламы

ЗАПУСК
  1. Установи Java 25 (например, Eclipse Temurin / Adoptium JDK 25).
  2. Открой minecraft-server\jvm.args и поставь память под свой ПК:
     сейчас -Xms16G -Xmx16G. Для ПК с 8–16 ГБ ставь -Xms4G -Xmx6G.
  3. Запусти minecraft-server\NeyroCraft.bat now
     (или start.bat). Первый запуск дольше: Paper подготовит файлы.
  4. В консоли выдай себе права: op ТвойНик
  5. Дай себе префикс директора: prefix set ТвойНик director

АДРЕС СЕРВЕРА (обязательно поменяй на свой)
  minecraft-server\plugins\NeyroHub\config.yml:
    server-address: твой-адрес          (домен или IP сервера)
    voice-pack → public-url: "http://твой-адрес:8165/neyrocraft-voice.zip"
  Без этого игроки не получат ресурс-пак (голос Саманты, модели, звуки, экран кино).

ПОРТЫ (проброс на роутере или открыть на хостинге)
  25565 TCP — игра
  8165  TCP — раздача ресурс-пака
  Для Windows можно запустить minecraft-server\open-firewall.bat.

ПОЛЕЗНЫЕ КОМАНДЫ
  /reboot [сек] | off | cancel — перезапуск с объявлением голосом Саманты
  /prefix … — ранги и префиксы, /rg … — приваты, /pass — StarPass
  /orion, /sabers, /race, /kino, /space — быстрый переход в режимы
  /neyrohub rebuild — перестроить хаб

МИРЫ
  Хаб, станция «Орион», арены, кинотеатр, станция «Аврора» с астероидами, планета Терракс
  и мир Minecraft 1.0 уже построены. Мир SkyBlock создастся заново при первом заходе.
  Данные игроков, аккаунты, логи и баны удалены — сервер «чистый».

СБОРКА ПЛАГИНОВ ИЗ ИСХОДНИКОВ
  source\neyrohub-src и др.: Java 25, javac --release 25 с библиотеками из
  source\neyrotab-src\buildlib (Paper API 26.3). Ресурс-пак собирается
  source\retropack-src\build-voicepack.ps1 (звуки конвертируются через Blender).
  NeyroHub целиком: source\neyrohub-src\build.ps1 (с ключом -Install кладёт jar в
  plugins\update — Paper подменит плагин при следующем перезапуске).

NEYRO-CITY — КИБЕРПАНК-ГОРОД НА СПАВНЕ ВЫЖИВАНИЯ
  Строится сам при первом запуске вокруг точки спавна мира (1–3 минуты, сервер при этом
  работает; ход стройки — в консоли). Над городом висит корабль NEYRO-1.
  • Безопасная зона внутри стен: нет PvP и урона, мобы не появляются, ломать/строить нельзя
    (операторы в креативе могут). Строить можно за стенами.
  • Новые игроки и умершие без кровати появляются в городе. /city — вернуться в город.
  • Луч в центре площади — лифт на корабль (хаб). Портал «Выживание» на корабле, если игрок
    шёл в город, спускает его по лучу с анимацией.
  • 8 магазинов вокруг площади, торговля за изумруды; «Ломбард 24/7» покупает ресурсы.
  • Вокруг стены земля сглажена: ровное кольцо 6 блоков, потом плавный склон 32 блока
    (горы срезаны, ямы засыпаны, море не осушается — над ним делается песчаный берег).
  • Клоны-стражи (18 шт.): у ворот, на углах стены, у луча и 4 патруля на проспектах.
    Стреляют бластерами по монстрам у города, неуязвимы. Злодеев не трогают, но следят.
  • Музыка города: синтвейв (voicepack-src\city_music.py → city_music.ogg в ресурс-паке),
    без пака играет пластинка Creator.
  • Выход в выживание и в скайблок через порталы корабля — спуск по лучу (BeamDrop.java).
  • Свет и Тьма (NeyroKarma.java): убийства игроков/жителей/питомцев тянут к тьме,
    монстры и время — к свету; злодеям цены в городе ×1.5–2, за их голову — награда.
    Инвентарь на E (с ресурс-паком) — в том же стиле, с моделью игрока; сторона видна
    там как эффект «Светлая сторона» (синий) / «Тёмная сторона» (красный), уровень II —
    герой/лорд (это переименованные «Удача»/«Неудача»). Экран со всеми цифрами: Shift+F
    или /char. Картинки: voicepack-src\gui_character.py и gui_inventory.py (там же скин
    клонов-стражей clone_trooper.png; без ресурс-пака игроки видят стражей в белой броне).
    Ресурс-пак собирается source\retropack-src\build-voicepack.ps1.
  • /neyrocity info | rebuild | dump — для админов. Настройки (config.yml):
    city.enabled: false — выключить город; city.center-x / center-z — центр (до первой стройки).
  • Состояние: plugins\NeyroHub\city.yml. /neyrocity rebuild перестраивает город на месте;
    если удалить city.yml и перезапустить сервер — город заново выберет высоту и центр.
  • Копия мира вокруг спавна до постройки города: minecraft-server\backup-before-city\
    (файлы region r.-1.-1 … r.0.0 — вернуть их можно только при выключенном сервере).
  Код: source\neyrohub-src\src\net\neyrocraft\hub\NeyroCity.java (город, NPC, зона, луч),
  CityPlan.java (планировка и здания), CityShops.java (магазины и цены).

КОРАБЛЬ NEYRO-1 (ХАБ) — МОДЕЛЬ В BLENDER
  source\ship-src\neyro1.blend   — модель корабля (1 единица Blender = 1 блок,
                                   нос смотрит на север, Z = 0 — пол палубы)
  source\ship-src\build_ship.py  — скрипт, который строит эту модель с нуля
  source\ship-src\voxelize.py    — переводит модель в блоки Minecraft и рисует превью
  source\ship-src\renders\       — картинки корабля
  Палубу с порталами и куполом строит сам плагин, модель — это корпус вокруг неё.
  Как поменять корабль:
    1. Правишь neyro1.blend (или build_ship.py и запускаешь
       blender --background --python build_ship.py).
       У каждой детали есть свойство mc_role: hull, wing, engine, glass, tower, fin...
       — по нему выбираются блоки и раскраска.
    2. blender neyro1.blend --background --python voxelize.py
       → source\neyrohub-src\resources\ship\neyro1.ship.gz и картинки в renders\
    3. source\neyrohub-src\build.ps1 -Install, перезапуск сервера, затем в игре
       /neyrohub rebuild (или подними BUILD_VERSION в NeyroHub.java — тогда
       корабль перестроится сам при запуске).
